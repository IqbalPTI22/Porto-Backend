Projects Table

Tambah proyek baru: isi judul, deskripsi, link gambar, dan link proyek. Semua kolom wajib.

ID Title Description Project URL

Create Project

Nama proyek yang mudah dipahami pengunjung.

Link demo atau halaman proyek.

Contoh: Aplikasi kasir untuk mencatat transaksi harian dan stok barang.

Link gambar thumbnail proyek.

Update or Delete Project

Ambil ID dari kolom pertama pada tabel.

Skills Table

Tambah skill baru: isi nama skill, level kemampuan, dan kategori.

ID Name Level Category

Create Skill

Nama kemampuan, misalnya: React, PostgreSQL, UI Design.

Gunakan level yang konsisten agar rapi.

Kelompokkan skill supaya mudah dipahami.

Update or Delete Skill

Isi ID dari tabel skill.

Profile Table

Tambah profil utama: data ini biasanya tampil di halaman About atau Hero.

ID Full Name Headline Email Location

Create Profile

Nama lengkap sesuai yang ingin ditampilkan publik.

Jabatan singkat, contoh: Web Developer.

Tulis ringkas 2-4 kalimat agar mudah dibaca.

Email aktif untuk kontak kerja.

Kota domisili, contoh: Bandung.

Link foto profil dengan resolusi jelas.

Update or Delete Profile

Pilih ID dari tabel profil yang ingin diubah/hapus.
